# BIBLUNE — A little world of books

A refreshed, responsive front-end bookstore project.

## Open the project
1. Extract the ZIP folder.
2. Open `index.html` in a browser, or open the folder in VS Code.
3. For local development, use VS Code Live Server if available.

## Pages
- `index.html` — Home
- `Books.html` — Searchable, filterable book collection
- `Categories.html` — Curated collections
- `About.html` — Story and project credits
- `Register.html` — Client-side registration form demo

## Included interactions
- Responsive mobile navigation
- Book search, category filter and sorting
- Shopping bag with quantity controls, remove actions and subtotal
- Browser-local cart persistence using localStorage
- Newsletter and registration form front-end validation / demo feedback

## Important demo limitations
This is a front-end project. The cart is saved in the current browser only. Checkout does not take payments or submit orders, and the newsletter/registration forms do not send data to a server. A real store would need a secure backend and payment integration.

The book titles, cover images and listed prices are based on the supplied project files. Please verify the factual details and prices before using this as a live shop.
